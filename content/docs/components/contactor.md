# 接触器

接触器是**频繁通断主回路**的电磁开关，结构与继电器相同（线圈、衔铁、触点），区别在于它带**灭弧装置**、触点容量大，能直接通断电机等大电流负载。设备类别代号为 **K**；用在电动机控制回路中时，标识符常用 **M** 表示该接触器所控制的电动机。

## 一、结构与部件

- **电磁机构**：线圈 + 静铁芯 + 动铁芯（衔铁）。线圈得电吸合，失电靠反力弹簧释放。
- **主触点**：三对常开触点，接三相主回路，触头大、带灭弧罩。
- **辅助触点**：小容量触点，接控制回路，用于自锁、互锁、信号指示。
- **灭弧装置**：主触点通断时电弧较大，靠灭弧罩（栅片）把电弧拉长冷却、加速熄灭。
- **底座与接线端子**：主回路端子标 L1/L2/L3 与 T1/T2/T3，控制线圈端子标 A1/A2。

| 项目 | 主触点 | 辅助触点 |
| --- | --- | --- |
| 所接回路 | 主回路（三相电源 → 负载） | 控制回路（线圈、按钮、指示灯） |
| 电流 | 大（额定工作电流 Ie） | 小（一般几安） |
| 常态 | 常开 | 常开、常闭都有 |
| 灭弧 | 有灭弧罩 | 无 |
| 用途 | 通断负载 | 自锁、互锁、给信号 |

按书上图 12-13 的画法：线圈画成**窄长方框、内部一条对角线**；触点的画法是——上引线末端接一个**小圆**（静触头），动触头是从它斜向下引出的**斜线**，斜线下端带一段**指向左的实心箭头线**（表示触点联动、动作方向）。常开的小圆与斜线之间**留断口**，常闭的斜线**搭在小圆上**；主触点三对并列，相邻两极之间用**虚线**连成一组，表示机械联动。

## 三、与热过载继电器配合

电机过载保护靠**热过载继电器**（热继电器），它串在主回路里，与接触器组装成一体使用。

**原理**：内部是**双金属片**——两种热膨胀系数不同的金属轧在一起，过载电流使它发热弯曲，推动机构切换常闭触点，从而切断接触器线圈回路，让接触器释放、主回路断电。三相热继电器还带**断相保护**。

**组装方法**（图 12-29、12-30）：

1. 把热继电器尾部的**固定挂钩**挂到接触器底部的配件安装固定孔上。
2. 把热继电器的三个接线柱插入接触器输出接线螺钉的压接固定片下面，插到位，使两者紧密贴合、不留缝隙。
3. 旋紧接触器输出接线螺钉，完成稳定连接。
4. 接线柱可左右推动调节位置，按热继电器上的图形标识选择与接触器型号匹配的位置。

**铭牌参数**（以 CHNT NR2-25 为例，图 12-31）：

| 标识 | 含义 |
| --- | --- |
| 型号 | 系列与规格，如 NR2-25，25 表示该系列的框架等级 |
| 执行标准 | 符合的国家/行业标准 |
| **Ui** | 额定绝缘电压（如 690V） |
| **Trip class 10A** | 脱扣类别：负载电流达到 1.5 倍整定电流时，动作时间在 2～10s 之间 |
| **Ie** | 额定工作电流一列，对应本系列各个型号的整定电流范围 |
| **A (gG)** | 建议匹配的熔断器额定电流，gG 表示全范围保护型熔断器 |
| **Ith** | 发热电流（长期通过不发热超限的电流） |
| NO / NC | 辅助触点的常开、常闭关系 |

**符号与标识**：设备类别标识「F」对应保护装置、「R」代表继电器类别，所以热继电器写作 **FR1**、**FR2**。图形符号（图 12-32）是三个**热元件**（主回路三相各串一个）加延时动作的辅助触点：常闭 95-96 过载时断开、去切断接触器线圈，常开 97-98 过载时闭合、接报警或指示灯，两组触点用虚线与热元件联成一体。

> 图片待补充：教材图 12-32 热过载继电器图形符号（三个热元件、常闭触点 95/96、常开触点 97/98）。

**整定**：热继电器的整定电流按电机额定电流选取（一般取 1.0～1.1 倍），整定太小会误动作、太大则起不到保护作用。复位方式分手动/自动，过载脱扣后需查明原因再复位。

## 四、辅助触点不够时：扩展模块

本体辅助触点数量固定，控制回路需要的触点多于此数时，加装**辅助触点扩展模块**（图 12-33），功能与本体的辅助触点一致。

- **型号匹配**：模块必须与接触器型号适配，不匹配会装不上或动作异常。
- **安装方式**：分**正面加装**（插在接触器顶部）和**侧面加装**（卡在侧面），按模块结构选择。
- **触点组合**：模块型号里的数字表示触点构成，常见 10＝一常开、01＝一常闭、11＝一常开一常闭、04＝四常开、08＝两常开两常闭（32A 及以下与 40A 及以上可选的组合不同，以厂家手册为准）。

## 五、常用控制回路

**电机正反转**（图 12-41）：两只接触器 KM1、KM2 分别接正序与反序电源（任意两根相线对调），主回路前串空气开关 QF1 和热继电器 FR1；控制回路上 SB1 停止、SB2 正转、SB3 反转，各自自锁，并把对方的常闭触点串进自己的支路做**互锁**——这与 [继电器](/docs/components/relay/)的互锁电路结构完全一样，只是把继电器换成了接触器线圈。互锁之外，正反转通常还要加**机械联锁**，防止两只接触器同时吸合造成相间短路。

**星三角降压启动**（图 13-10、13-11）：主接触器 KM1 送电、KM3 先接成星形降压启动，[时间继电器](/docs/components/time-relay/) KT 延时到后切断 KM3、接通 KM2 转成三角形全压运行。整个过程由接触器 + 时间继电器 + 热继电器协同完成，是接触器最典型的组合应用。

## 六、选用与接线注意

- **线圈电压**必须与控制电源一致（AC220V、AC380V、DC24V…），接错直接烧线圈。
- **额定工作电流 Ie** 按负载类别和电压查表选取，电机负载还要考虑启动电流与操作频率。
- 主回路接线后先手动按动衔铁（部分产品带手动测试按钮）检查触点动作，再通电试车。
- 触点烧蚀、线圈发热、吸合有异响都属于故障前兆，停电检查触头压力与铁芯短路环。
