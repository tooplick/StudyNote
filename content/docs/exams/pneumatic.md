# 气动与传感器

> 对应原卷题号 19、20。

## 第 19 题 · 气路电磁阀类型与阀体示意

**题目**：气路常见电磁阀有几种类型，画出每种类型的电磁阀阀体示意图，并用文字表明图形含义。

**答案**

**按位数和通路数分**：二位三通、二位五通、三位五通（另有三位二通、二位二通等）；按控制方式分单电控、双电控。

**阀体图形含义**

- 阀体由几个方块组成，**每个方块是一“位”**（一工位），方块里有几个接口连通用几个字母表示——**字母个数是“通”数**。
- 接口字母：**P** 进气，**A / B** 接用气口（气缸），**R / S** 排气口。
- 阀内箭头表示该位时的气流方向，T 形符号表示该口封闭。
- 方块之间的弹簧符号表示**弹簧复位**，电磁线圈符号（斜线加线圈/方框 Y）表示**电控**；单电控阀失电弹回原位，双电控阀无弹簧，靠另一侧线圈换位。

| 类型 | 用途 |
| --- | --- |
| 二位三通单电控 | 单作用气缸 |
| 二位五通单电控 | 双作用气缸（断电自动缩回） |
| 二位五通双电控 | 双作用气缸（有保持，需两侧交替给电） |
| 三位五通（中封/中泄/中压） | 中间位功能不同：中封锁定、中泄泄压、中压保持伸出 |

> [!NOTE] 补充
> 原答案为“略”。本段按常规教材符号补充；实物的完整阀体图见 [双缸往复](/docs/electromech/double-cylinder/) 原理图右侧（两个二位五通单电控阀）以及 [气动基础](/docs/electromech/pneumatics/)。

## 第 20 题 · NPN / PNP 磁性开关

**题目**：文字描述 NPN 与 PNP 输出信号的定义。绘制出两线制、三线制 NPN 与三线制 PNP 气缸磁性开关，控制 24V 中间继电器动作的接线图，标明每根线的线色。

**答案**

**定义**

- **NPN 型**：感应到信号（被磁铁触发）时，**黑线（信号线）输出负极**，即低电平 0V。负载一端接信号线，另一端接电源正极。
- **PNP 型**：感应到信号时，**黑线输出正极**，即高电平 24V。负载一端接信号线，另一端接电源负极。

**接线（控制 24V 中间继电器线圈）**

| 类型 | 棕线 | 蓝线 | 黑线 | 继电器线圈接法 |
| --- | --- | --- | --- | --- |
| 两线制 | 串在负载回路正极侧 | 回 0V | 无 | 两线开关即两端子：+24V → 继电器线圈 → 棕色线 → 开关 → 蓝色线 → 0V，**两线不能接反** |
| 三线制 NPN | +24V | 0V | 信号输出 | 黑线接线圈一端，线圈另一端接 **+24V** |
| 三线制 PNP | +24V | 0V | 信号输出 | 黑线接线圈一端，线圈另一端接 **0V** |

- 棕色＝电源正，蓝色＝电源负（或信号参考），黑色＝信号输出；继电器线圈两端一般并一只反向二极管作浪涌吸收。

**接线示意（按上图思路）**

```text
三线制 NPN：+24V ─ 棕 [开关] 蓝 ─ 0V
                    黑 ─── 线圈(A1) ─── 线圈(A2) ── +24V

三线制 PNP：+24V ─ 棕 [开关] 蓝 ─ 0V
                    黑 ─── 线圈(A1) ─── 线圈(A2) ── 0V

两线制：+24V ─ 线圈(A1) ─── 线圈(A2) ─ 开关线1 [开关] 开关线2 ─ 0V
```

> [!NOTE] 补充
> 原答案为“略”，上方定义与接线表是整理时按常见磁性开关（棕/蓝/黑三线，两线制无黑线）补写的。两线制磁性开关只有两根引线（多为棕、蓝），本身串在回路中，负载必须串在回路里，接反可能烧坏开关；不同厂家线色偶有差异，**以开关铭牌标注为准**。详见 [传感器](/docs/electromech/sensor/)。
