# 双缸往复

两个双作用气缸交替伸出、缩回，来回带动工件或机构，这套动作叫**双缸往复**。台面上的自动送料、压装、拨料等机构里很常见。

本篇整理自 FluidSIM-P 仿真图纸（最新版）：左侧为 24V 继电器控制线路，右侧为两路气动执行部分。

![双缸往复原理图](/images/double-cylinder.png "双缸往复原理图")

> 原图 PDF：[双缸往复.pdf](/pdf/double-cylinder.pdf)

## 一、气路部分

- **两套执行单元**：每套由一台双作用气缸和一个二位五通单电控电磁阀（YV1 / YV2）组成。
- **磁性开关**：气缸两端各装两只，1 号缸为 SQ1（后端）、SQ2（前端），2 号缸为 SQ3（后端）、SQ4（前端）；SQ1、SQ3 带向上箭头，为常开型。
- **电磁阀工作**：
  - **得电**：工作位移入，P→4、2→3 排气，气缸**伸出**；
  - **失电**：弹簧复位，P→2、4→5 排气，气缸**缩回**。
- 两阀进气口（1 口）前各串一个单向节流阀，图中调为 **50%**，用于控制伸出速度。

## 二、电气部分（DC 24V）

### 元件

| 元件 | 类型 | 作用 |
| --- | --- | --- |
| SB1 | 启动按钮（常开） | 按下启动一次循环 |
| SB2 | 停止按钮（常闭） | 切断控制电源 |
| SQ1–SQ4 | 磁性开关 | 检测气缸到位 |
| KA1 | 中间继电器 | 主控，启动自锁 |
| KA2 | 中间继电器 | 1 号缸前端 SQ2 到位，自锁 |
| KA3 | 中间继电器 | 2 号缸前端 SQ4 到位 |
| KA4 / KA5 | 中间继电器 | 1 号缸后端 SQ1 / 2 号缸后端 SQ3 到位检测 |
| KA6 | 中间继电器 | 启动回路，接在 SB2 之后、SB1 自锁两侧 |
| YV1 / YV2 | 电磁阀线圈 | 控制两缸伸出，均并联反向二极管 |

### 各支路

| 支路 | 串接内容 | 说明 |
| --- | --- | --- |
| 1 | 24V → KA6 常开 → KA4 常开 → KA5 常开 → KA1 线圈 → KA3 常闭 → 0V | 两缸都在后端且 KA3 未动作时，KA1 才能得电 |
| 2 | KA1 常开 → YV1 | 启动后 1 号阀得电 |
| 3 | KA1 常开 → YV2 | 启动后 2 号阀得电，两缸同时伸出 |
| 4 | KA2 常开 → YV2 | KA2 动作后保持 2 号阀得电 |
| 5 | （经支路 5 取电）SQ2 ∥ KA2 自锁 → KA2 线圈；线圈下端串 KA4 常闭 | KA2 自锁回路，1 号缸离开后端（KA4 失电）后才允许自锁 |
| 7 | SQ4 → KA3 线圈 | 2 号缸前端到位 |
| 8 | SQ1 → KA4 线圈 | 1 号缸后端到位 |
| 9 | SQ3 → KA5 线圈 | 2 号缸后端到位 |
| 10 | 24V → SB2（常闭）→ KA6 常开 ∥ SB1 自锁 → KA6 线圈 | KA6 启动自锁回路 |
| 11 | SB2 之后并接 SB1 与 KA6 常开 | 启动自锁点 |

### 动作过程

1. **初始**：两缸在后端，SQ1、SQ3 压合，KA4、KA5 吸合；KA3、KA6 未动作。
2. **启动**：按 **SB1**，KA6 吸合并经支路 10、11 自锁；KA6 常开接通支路 1（此时 KA4、KA5、KA3 常闭均接通），KA1 吸合并自锁。
3. **伸出**：KA1 常开（支路 2、3）使 YV1、YV2 得电，两缸同时伸出。
4. **到位**：SQ1、SQ3 释放，KA4、KA5 失电；两缸前端到位后 SQ2、SQ4 压合。
   - SQ2 使 KA2 吸合并自锁（支路 4、5），继续给 2 号阀保持信号；
   - SQ4 使 KA3 吸合，KA3 常闭切断支路 1，KA1 释放，YV1 失电，1 号缸缩回。
5. **缩回**：1 号缸回后端 SQ1 压合，KA4 吸合，其常闭断开、KA2 释放，YV2 失电，2 号缸缩回。
6. **循环**：两缸都在后端后，按 SB1 再次启动；按下 **SB2** 可随时切断 KA6，整套回路复位。
