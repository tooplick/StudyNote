# 双缸往复

两个双作用气缸交替伸出、缩回，来回带动工件或机构，这套动作叫**双缸往复**。台面上的自动送料、压装、拨料等机构里很常见。

本篇整理自 FluidSIM-P 仿真图纸（最新版）：左侧为 24V 继电器控制线路，右侧为两路气动执行部分。

![双缸往复原理图](/images/double-cylinder.png "双缸往复原理图")

> 原图 PDF：[双缸往复.pdf](/pdf/double-cylinder.pdf)

### 动作过程

1. **初始**：两缸在后端，SQ1、SQ3 压合，KA4、KA5 吸合；KA3、KA6 未动作。
2. **启动**：按 **SB1**，KA6 吸合并经支路 10、11 自锁；KA6 常开接通支路 1（此时 KA4、KA5、KA3 常闭均接通），KA1 吸合并自锁。
3. **伸出**：KA1 常开（支路 2、3）使 YV1、YV2 得电，两缸同时伸出。
4. **到位**：SQ1、SQ3 释放，KA4、KA5 失电；两缸前端到位后 SQ2、SQ4 压合。
   - SQ2 使 KA2 吸合并自锁（支路 4、5），继续给 2 号阀保持信号；
   - SQ4 使 KA3 吸合，KA3 常闭切断支路 1，KA1 释放，YV1 失电，1 号缸缩回。
5. **缩回**：1 号缸回后端 SQ1 压合，KA4 吸合，其常闭断开、KA2 释放，YV2 失电，2 号缸缩回。
6. **循环**：两缸都在后端后，按 SB1 再次启动；按下 **SB2** 可随时切断 KA6，整套回路复位。
