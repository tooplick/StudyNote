# 电机

> [!NOTE] 待整理
> 这一篇后续补充三相异步电机的工作原理、星形/三角形接法、铭牌参数，以及星三角启动和正反转控制。

常见关注点：

- **三相异步电机**：最常见，铭牌上标有额定电压、电流、功率、转速、接法（Y 或 △）。
- **接法**：380V 电源下额定 380V△/660VY 的电机多为 △ 接；星三角启动需要 380V 下为 △ 接的电机。
- **转向**：任意调换两根相线即可反转，实际正反转控制由 [接触器](/docs/components/contactor/) 互锁实现。
- **过载保护**：主回路中串入热继电器。
