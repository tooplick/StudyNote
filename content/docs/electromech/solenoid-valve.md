# 电磁阀

电磁阀是气动回路的**控制元件**：线圈通电产生电磁力推动阀芯换位，改变气路的通断与流向，从而控制气缸伸出、缩回。它把电信号变成气动作，是电控气动系统里电气与气动的交接口（气源、气缸等见 [气动基础](/docs/electromech/pneumatics/)，典型用法见 [双缸往复](/docs/electromech/double-cylinder/)）。

> 本篇按教材 14.5 节整理（p.193–199），图形符号按教材版式重绘。

## 一、结构

一只常用的五通电磁阀由这几部分组成：

- **阀体**：内部是圆柱形空腔，阀芯在其中滑动。
- **阀芯**：带活塞的连杆，活塞上装 O 形密封圈，把阀体分成两侧的腔（对应 A、B 两个工作口）。
- **线圈 + 先导头 + 端盖**：装在阀体端部，通电后产生电磁力吸合衔铁。
- **手动测试按钮**：调试时不用给电就能手动顶动阀芯，检查气路是否通畅。
- **手动调整位置**：在阀芯一侧，可用工具手动推阀芯到另一动作位。
- **接线端子**：线圈电源进线处，常见 DC 24V 或 AC 220V。
- **安装孔与固定螺母**：阀体正面和顶部各有一组安装孔，可按需要选装；端部固定螺母可拆下。

## 二、五个孔位

阀体上有 A、B、R、P、S 五个孔位，记住这五个字就够读懂后面的所有符号：

| 孔位 | 含义 | 说明 |
| --- | --- | --- |
| P | 进气口 | 接气源（经单向节流阀、气源处理件） |
| A | 工作口 1 | 接气缸一腔 |
| B | 工作口 2 | 接气缸另一腔 |
| R | 排气口 | A 的排气，经消声器排空 |
| S | 排气口 | B 的排气 |

现场阀体上常印 1/2/3/4/5 编号，对应关系是 **P=1、A=4、B=2、R=5、S=3**。接管时按这个编号对位，比记字母不容易错。

## 三、怎么看图形符号

![电磁阀图形符号的基本要素](/images/valve/symbol-elements.svg "图形符号的基本要素")

| 图形要素 | 含义 |
| --- | --- |
| 方块 | 阀体，**一个方块代表一个动作位置（一位）** |
| 箭头 | 该位置下气流的通路方向 |
| T 形（⊥ / ⊤） | 该孔位封闭不导通 |
| 折线（弹簧） | 弹簧复位，失电后阀芯被推回这一位 |
| 矩形里的三角形 | 电磁铁（线圈），三角形朝向阀体 |

几条读图规则：

- **方块个数 = 位数**，孔位个数 = 通数，所以「两位五通」就是两个方块、五个孔。
- 孔位（A B 在上、R P S 在下）画在**当前动作位置**的方块上；切换到另一动作位时，等于把相邻方块挪到孔位之间。
- 教材画法：两位阀画两个方格，一格是图示动作位、一格是另一动作位；三位阀画三个方格，中间那格就是弹簧对中后的中位。

## 四、类型划分

- **按线圈数量**：单电控（一个线圈，另一端靠弹簧复位）、双电控（两端各一个线圈）。
- **按孔位数（通）**：两通、三通、五通。
- **按阀芯位置数（位）**：两位、三位。

组合起来就是平时说的型号，例如「单电控两位五通」「双电控三位五通」。

## 五、五种常用阀

### 1. 单电控两位五通

![单电控两位五通电磁阀符号](/images/valve/valve-2p-single.svg "单电控两位五通")

- 一端是线圈，另一端内部装弹簧，只有两个动作位置。
- **失电**（图示位）：阀芯被弹簧顶住，P→A 导通、B→S 导通，R 封闭 → 气缸**缩回**。
- **得电**：电磁力把阀芯推到位，P→B 导通、A→R 导通，S 封闭 → 气缸**伸出**。
- 断电瞬间弹簧立即复位，所以掉电时气缸会自动回到缩回位，这是单电控最要紧的特性。
- [双缸往复](/docs/electromech/double-cylinder/) 里的一缸一只阀就是这种：YV1 得电 1 号缸伸出、YV1 失电缩回，YV2 对 2 号缸同理。

### 2. 双电控两位五通

![双电控两位五通电磁阀符号](/images/valve/valve-2p-double.svg "双电控两位五通")

- 两端各有一个线圈，没有弹簧。
- **左端线圈得电**：P→A、B→S，R 封闭。
- **右端线圈得电**：P→B、A→R，S 封闭。
- **两端都失电**：阀芯**停在最后一次得电的位置**（有记忆），所以断电后气缸保持不动。
- 两个线圈不能同时得电，否则阀芯受力冲突，控制回路里必须做互锁（继电器常闭互锁或 PLC 程序互锁）。

### 3. 双电控三位五通（中封 / 中泄 / 中压）

两端各一个线圈、各一个对中弹簧，中间多出第三个位置，按**中位的通断方式**再分三种。

**中封式**：中位五个孔位全部封闭。

![双电控三位五通中封式符号](/images/valve/valve-3p-closed.svg "三位五通中封式")

- 左、右端得电与双电控两位五通相同。
- **两端都失电**：阀芯被弹簧对中，A、B、P、R、S 全封 → 气缸两腔都被封住，活塞**停在中途**。

**中泄式**：中位 P 封闭，A、B 分别通 R、S 泄压。

![双电控三位五通中泄式符号](/images/valve/valve-3p-exhaust.svg "三位五通中泄式")

- 中位：A→R、B→S，P 封闭 → 两腔压力经消声器泄掉，活塞**失去推力**，可被外力推动。

**中压式**：中位 R、S 封闭，P 同时通 A、B。

![双电控三位五通中压式符号](/images/valve/valve-3p-pressure.svg "三位五通中压式")

- 中位：P→A、P→B，R、S 封闭 → 两腔**同时进气**，活塞两侧受压、推力基本平衡。

三种中位怎么选：

| 中位形式 | 中位通路 | 气缸在中位的状态 | 典型用途 |
| --- | --- | --- | --- |
| 中封式 | A B P R S 全封 | 两腔封死，停在原位 | 中途停位、需要保住位置 |
| 中泄式 | P 封，A→R、B→S | 两腔泄压，可自由推动 | 允许手动复位、安全卸压 |
| 中压式 | P→A、P→B，R S 封 | 两腔同压，活塞受力平衡 | 需要两侧同时施力或防止漂移 |

> [!NOTE]
> **补充**：中封式靠封闭两端气缸腔来保位，本质上依赖密封件，长时间保压会因内泄漏缓慢漂移，不能当机械锁用；要求可靠停位时用带锁气缸或机械定位。

## 六、直动式与先导式

按动作原理，电磁阀还分两类：

- **直动式**：电磁力直接驱动阀芯换位，不依赖气压。真空、零压、低压场合也能动作，缺点是受线圈体积限制，通径一般做不大（教材给到 25mm 量级）。
- **先导式**：用一小股先导气推动主阀芯，线圈只负责开先导孔，因此可以做大口径、低功耗；但需要最低工作气压。

现场判断方法：阀体上先导头（带先导孔、先导膜片）的就是先导式；按压手动测试按钮时若能直接感到阀芯到位，多半是直动式。

## 七、接线与调试

- 线圈电压核对铭牌（DC 24V / AC 220V 都常见），**直流线圈并联反向续流二极管**，抑制断电反电动势。
- 线圈功率小、电流不大，但感性负载，多只线圈共用一个电源时注意总电流与公共 0V 线径。
- 调试时用**手动测试按钮**先确认气路与气缸动作方向，再接线试电，可避免误判线圈或接线问题。
- 气缸速度用进/排气口的**单向节流阀**调节，常用排气节流，与阀本身无关。
- 气缸到位检测靠缸上的磁性开关，接线（两线制 / 三线制 PNP·NPN）见 [传感器](/docs/electromech/sensor/)。
