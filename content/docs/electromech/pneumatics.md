# 气动基础

> [!NOTE]
> **待整理**：后续补充气源处理件、气缸与常见气动回路，电磁阀部分已单独整理。

在电气控制中，气动常用于执行动作，和电控配合形成了 **电控气动** 系统（电磁阀线圈由继电器/接触器/PLC 输出控制）。

常见元件：

- **空压机 + 储气罐**：提供压缩空气。
- **气源处理件（FRL）**：过滤、减压、油雾，常用两联件或三联件。
- **电磁阀**：电信号控制气路切换，常见二位五通、三位五通，线圈多为 DC 24V 或 AC 220V（结构、符号与五种常用阀见 [电磁阀](/docs/electromech/solenoid-valve/)）。
- **气缸**：单作用靠弹簧复位，双作用需要两路进气。
- **节流阀 / 单向节流阀**：调节气缸速度，常用排气节流。
- **磁性开关**：装在气缸上检测活塞位置，输出信号给控制系统（见 [传感器](/docs/electromech/sensor/)）。
